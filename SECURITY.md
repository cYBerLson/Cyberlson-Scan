# Security Policy

## Reporting a Vulnerability

Cyberlson Scan is an educational defensive cybersecurity project.

If you discover a security vulnerability, please **do not** disclose it publicly by opening a GitHub Issue.

Instead, report it privately using the contact information below.

## Contact

**Email:** cyberlsoncs@gmail.com

Please include:

- A description of the vulnerability
- Steps to reproduce it
- The affected version
- Screenshots or logs (if available)

I will investigate the report as quickly as possible and work on an appropriate fix.

Thank you for helping improve the security of Cyberlson Scan.
